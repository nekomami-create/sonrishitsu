# ソンリシツ判定くん

手書きの「ソ・ン・リ・シ・ツ」を、書き上がった形だけで判定する Web アプリです。

**https://nekomami-create.github.io/sonrishitsu/**

## 使い方

升目に指かマウスで書くと、その場で判定します。ソ・ン・リは2画、シ・ツは3画で書いてください。

## 判定のしくみ

一番長い画を「長い画」、残りを「点」とみなし、角度や形を測って点数にします。
書き順と書く向きは使いません（チェックボックスで書く向きも使うモードに切り替えられます）。

| 特徴 | 測るもの | 境目 |
|---|---|---|
| ① 点の立ち具合 | 点（リの左の画）がほぼ垂直か | 68° |
| ② 字の縦横比 | 字の幅 ÷ 高さ（リは細長い） | 0.76 |
| ③ 点の傾き | 点が水平から何度立っているか | 45° |
| ④ 点の並び | 2つの点を結ぶ線の角度（ツは横並び、シは縦並び） | 40° |
| ⑤ 長い画の傾き | 長い画の端から端の角度 | 45° |
| ⑥ 交差角 | 点と長い画の書き出しがなす角 | 50° |
| ⑦ 書いた向き（書き順オン時のみ） | 長い画を上→下に書いたか | |

- 2画: ① + ② > 0 ならリ。違えば ③ + ⑤ + 0.25×⑥ > 0 でソ、それ以外はン
- 3画: ③ + ④ + ⑤ + 0.25×⑥ > 0 でツ、それ以外はシ
- 書き順オンのときは、⑦ の向きがはっきりしていれば形より優先し、上→下でソ・ツ、下→上でン・シと決めます

境目は Google Fonts の和文フォント 36 書体で測った値から決め、別の 19 書体で確かめました（正解率 94%）。
